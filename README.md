# 🏡 Airbnb Rating Prediction — Data Science Capstone (NEBIUS)

This repository contains **Data Science Capstone Project** for the **NEBIUS Data Science Course**, built around the **Airbnb dataset**.
The project focuses on **Exploratory Data Analysis (EDA)** and **building a model to predict listing scores **, following **Python data science best practices**.

---

## 📌 Project Goals

- Perform **clean and structured EDA**
- Identify key factors that influence Airbnb listing performance
- Train and evaluate ML models for **score prediction**
- Keep the workflow **reproducible, readable, and well-documented**

---

## 🔍 What’s Inside

- ✅ Data cleaning & preprocessing
- ✅ Exploratory Data Analysis (EDA) + visual insights
- ✅ Feature engineering
- ✅ Model training + evaluation (baseline → improved models)
- ✅ Best practices: modular code, clear structure, reproducibility

---

## 🛠 Tech Stack

- Python
- Pandas / NumPy
- Matplotlib / Seaborn
- Scikit-learn
- Jupyter Notebook
